# Roman / Hammlet binary signal batch100 results

Local diagnostic results for the broad `s`/`q` binary-event sample.
The figures are one light-curve panel plus one Δχ² map per event.

## Run snapshot

- Events: `9920000`–`9920099` (100 total)
- Data: 23,104 valid points per event, all three seasons
- Search: `M=128`, `n_alpha=540`, radial order `1`
- Execution: `16 workers × 1 thread`, requested cores `16`
- χ² guarantee: disabled (single-resolution local diagnostic)
- Map snapshot: `33903` readable maps from `packed_atlas-current33903-m512`
- The 90 not-yet-readable maps were intentionally excluded from this snapshot; production map files were not modified.
- SGE scan job: `830316`
