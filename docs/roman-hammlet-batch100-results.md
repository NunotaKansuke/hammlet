# Roman / Hammlet batch100 local results

Local static snapshot of the 100-event Roman/Hammlet scan. Each figure shows the best FFT seed light curve on the left and the corresponding adaptive \(\Delta\chi^2\) map on the right.

## Run note

- Events: `9910000`–`9910099` (100 events)
- Data points per event: `23,104`
- FFT map evaluation: `M=128`, `n_alpha=540`, radial order `1`
- Parallelism: `16 workers × 1 thread`
- χ² guarantee: disabled
- Atlas snapshot: packed `current33903-m512` cache
- This is a local test snapshot; the production atlas was not modified.
