# Roman/Hammlet test type: intermediate / close

This page contains all 9 events whose GULLS truth parameters satisfy **intermediate** in `q` (1e-2 <= q < 1e-1) and **close** in `s` (0.45 <= s < 0.70). The split is a bookkeeping partition of the injected parameters; it is not an outcome-based selection.

The displayed `s` value follows the GULLS host-only Einstein-scale convention used for this test set. The event figure is the corresponding entry in the batch-level report. A figure or metadata row should not be read as a proof that the trajectory crosses a caustic.
