# Roman/Hammlet test type: planetary / resonant_range

This page contains all 64 events whose GULLS truth parameters satisfy **planetary** in `q` (q < 1e-2) and **resonant_range** in `s` (0.70 <= s < 1.35). The split is a bookkeeping partition of the injected parameters; it is not an outcome-based selection.

The displayed `s` value follows the GULLS host-only Einstein-scale convention used for this test set. The event figure is the corresponding entry in the batch-level report. A figure or metadata row should not be read as a proof that the trajectory crosses a caustic.
